Truthiness & Falseness of value

In JavaScript, values can be classified as either "truthy" or "falsy" based on how they are evaluated in a boolean context. A value is considered "truthy" if it evaluates to true when used in a conditional statement, while a value is considered "falsy" if it evaluates to false.

Here are some examples of truthy and falsy values:

  • Truthy values: "hello", 42, true, [], {}
  • Falsy values: false, 0, -0, 0n, "", null, undefined, NaN
